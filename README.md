# Klangbar

Mac-App zum Durchsuchen und Vorhören großer Sound-Bibliotheken – mit UCS-Kategorien, Favoriten,
Ausschnitten per Drag & Drop und Export nach Avid Media Composer und als WAV.

## Herunterladen

**[Neueste Version herunterladen](../../releases/latest)** – dort die Datei `Klangbar-….dmg` laden.

1. DMG öffnen und **Klangbar** in den Ordner **Programme** ziehen.
2. Beim allerersten Start: im Programme-Ordner **Rechtsklick auf Klangbar › Öffnen** und noch einmal
   **Öffnen** bestätigen. macOS fragt das nur beim ersten Mal, weil die App nicht über den App Store kommt.
3. Fertig. Eine Kurzanleitung liegt in der DMG.

Voraussetzungen: Mac mit Apple-Chip (M1 oder neuer), macOS 12 oder neuer.

## Updates

Klangbar schaut beim Start kurz hier nach, ob es eine neue Version gibt, und bietet sie mit einem Klick an.
Jedes Update ist digital signiert – Klangbar installiert nur Updates, deren Signatur stimmt.
Abschalten lässt sich das unter **Einstellungen › Allgemein › Updates**.
